# Folder Foto

Gunakan folder ini untuk menyimpan file foto berdasarkan kategori penggunaannya.

Struktur:
- profiles/ -> foto profil pengguna
- portfolios/ -> foto portofolio atau project
- jobs/ -> foto pekerjaan atau lowongan
- banners/ -> foto banner landing page atau hero
- avatars/ -> avatar default / icon pengguna
- misc/ -> foto lain yang belum masuk kategori

Pastikan nama file deskriptif dan unik agar mudah dikelola.
